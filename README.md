# AI Avatar Revolution - Luxury Presentation

A stunning, high-end presentation website built with React showcasing the future of AI avatars in content creation. Features modern liquid glass styling, smooth animations, and professional design.

## Features

- **20 Full-Screen Slides** covering the complete AI avatar journey
- **Liquid Glass Morphism** - Modern glassmorphism effects with blur and transparency
- **Framer Motion Animations** - Smooth, professional transitions and micro-interactions
- **Responsive Design** - Works beautifully on all devices
- **Premium Typography** - Playfair Display, Syne, Space Grotesk, and Inter fonts
- **Interactive Navigation** - Dot navigation with scroll progress indicator
- **Animated Visuals** - Custom SVG animations, orbiting elements, and glowing effects

- **React 19** - UI Framework

- **CSS Variables** - Dynamic theming
- **Google Fonts** - Premium typography

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Design System

### Colors
- Primary Gradient: `#667eea` → `#764ba2`
- Aurora Gradient: Multi-color animated gradient
- Glass Background: `rgba(255, 255, 255, 0.03)`
- Text Primary: `rgba(255, 255, 255, 0.95)`

### Typography
- Display: Playfair Display (serif)
- Headings: Syne (sans-serif)
- Body: Inter (sans-serif)
- Mono: Space Grotesk
