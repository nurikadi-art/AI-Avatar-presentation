# Meridian — Lumen Book Landing

A landing page for *Lumen* featuring a realistic 3D CSS hardcover book mockup.

## Highlights

- **Pure CSS 3D book** — cloth cover, foil title, spine, page block, top/bottom edges, contact shadow
- **Interactive tilt** — mouse-tracking perspective on the book
- **Motion** — float, sheen drift, ambient light, entrance fades
- **Responsive** — desktop full-bleed hero, stacked mobile layout

## Stack

- React 19 + Vite
- Framer Motion
- CSS 3D transforms (no images for the book)

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
